# Indie Film Collective

A multi-page, mobile-first responsive website built for the Indie Film Collective to connect independent filmmakers, showcase upcoming screenings, promote hands-on workshops, and foster creative collaborations.

## Pages Included
* `index.html` – Home page introducing the collective and festival volunteer opportunities
* `screenings.html` – Information and monthly schedule for independent film screenings
* `workshops.html` – Details and registration steps for hands-on filmmaking workshops
* `collaborations.html` – Community board for local cast and crew collaborations
